= gskd craft

工程协作 skills 与 omp 配套扩展，覆盖任务续接、设计取舍、界面验证、交付复查和脉络回顾。
Skills 可按目标宿主的约定接入；扩展仅用于 omp。

== 接入与更新

=== omp

将仓库克隆到独立源码目录，在仓库根执行：

[source,shell]
----
omp plugin link .
----

启动新会话后，omp 会自动发现 skills 并加载扩展。链接直接指向源码，无需复制文件或安装额外依赖，也不搬迁现有配置、凭证和会话数据。
使用命名 profile 时，改用 `omp --profile work plugin link .`。
更新仓库后，启动新会话即可加载更新。

=== 其它宿主

按宿主的安装或发现约定接入 `skills/` 下的 skill 目录。每个 skill 以 `SKILL.md` 为入口，补充资料位于其 `references/`；迁移时保留完整目录和相对引用。
`extensions/` 下的 omp 扩展不适用于其它宿主。

== Skills

* `gskd-orient`：处理补充、纠正、工作项插入、并行安排与暂停续接
* `gskd-design-review`：检查设计取舍、责任边界、生命周期与实际接入
* `gskd-gui-verification`：验证真实界面、输入交互及平台行为
* `gskd-delivery-review`：对照已接受要求，核对实现、证据和交付边界
* `gskd-recap`：梳理分析、决定、进展和续接位置，不自动执行历史任务；默认简明表格，事项名称前配状态图标，按需分表并共用图例，也可用自然语言选择状态分组、主题分组或时间线；详略与形式独立

各 skill 按需使用，不组成固定流水线；实际能力由宿主工具、权限和环境决定。已读内容仍适用时可复用，新证据引出疑点时只检查受影响边界。发现、读取或注入 skill 不等于落实其要求，应以实际行动和证据判断。

=== 待议方向

以下仅记录候选方向，尚未实现；名称暂定，不代表已安排实施。

* `gskd-inspect`（调查定位，考虑合并故障定位与性能调查）：围绕明确问题收集证据、建立可证伪假设并选择能区分原因的实验。故障方向覆盖首次故障、偶发异常和环境差异；性能方向明确真实负载与指标，建立基线、定位瓶颈并比较优化前后及成本转移。设计取舍仍由 `gskd-design-review` 承担；调查本身不构成修复或优化授权。

== omp 扩展

=== 故障自动续接

`task-recovery` 默认开启，为仍在运行的主会话续接暂时性上游通信故障，包括连接失败、超时、流异常结束、临时服务错误和限流。

[source,text]
----
/gskd-recovery status
/gskd-recovery off
/gskd-recovery on
----

* 优先让宿主内置恢复接管；仍未恢复时，按 30、60、120、300 秒逐步等待，附加少量抖动，并遵守可获得的服务端等待提示。明确的临时故障不设累计次数上限；未确认的通信故障最多试探两次。
* 账户额度耗尽、认证与配置错误、正常完成或主动取消不会反复续接；临时限流沿用宿主分类，不仅凭 quota／billing 等关键词判断。
* 沿用原会话和工具结果，不重放整个任务。缺少工具回执、无法确认是否执行时暂停并提示核实。
* 仅在冷却等待时于输入框上方显示提示，不占底部状态栏。`off` 取消待恢复任务；`on` 仅对后续故障生效。
* 续接回合正常结束且回执齐全才记为成功，统计含冷却等待的累计耗时及最近完成时间；同一恢复过程只计一次。`status` 查看统计，下一次输入或 recovery 命令会一次性提醒未读成功记录。统计仅存于当前会话内存，不代表业务任务完成。

支持存活的 TUI、长驻 RPC 和 SDK 主会话，不用于同进程子代理或已退出的一次性 print/json 进程。不重启 omp、不切换模型、不修改全局配置，也不要求额外 checkpoint。
TUI 的 Esc/Ctrl-C、停止、新输入和会话切换会撤销旧恢复；已提交的续接无法撤回。非 TUI 若缺少停止信号，可用 `off` 显式取消。

=== 工作树执行位置

`worktree-location` 观察主会话最近一次 bash 执行声明的目录，也支持通过 `write xd://bash` 发起的执行。在其它工作树执行时，于输入区下方靠右显示单行 `wt: 工作树 · 分支`，不附加前导空行，不改底部状态栏；回到会话工作树后隐藏。若显式约定与实际位置不一致，仍保留偏离提示。

[source,text]
----
/gskd-worktree status
/gskd-worktree set <path>
/gskd-worktree clear
----

* 默认命令与 `status` 查看完整路径、分支、HEAD、观测来源和显式约定。
* `set` 仅绑定任务工作树，不切目录；尚未观测执行时不显示常驻行。`clear` 清除约定，保留最近执行记录。
* 只依据结构化 `bash.cwd`，缺省采用会话目录；不追踪 shell 内部 `cd`、`git -C`、远端目录或产物来源。沿用宿主路径规则，包括 `/` 的工作区别名、`@` 前缀和 `file://`；显式 `set /` 仍指文件系统根目录。
* 最终位置以规范执行回执为准；等待回执时标为待确认。审批拒绝或未执行不算观测，已执行的非零退出和超时仍可记录。目录或 Git 信息不可用时不猜测分支。
* 已确认状态随成功的会话／分支切换恢复；旧回执或查询不能覆盖更新状态，也不能跨入新会话。取消会话切换不丢弃仍有效的在途观测。

执行 `/move` 或迁移工作区后，用 `status` 或下一次 bash 执行刷新基准与显示；宿主清除提示后也可这样恢复。扩展不轮询目录、不修改宿主、不拦截执行或注入模型上下文；非 TUI 仅通过命令查看。

=== 轻量显示预设

`display-preset` 仅用于主 TUI 会话，按需启用：

[source,text]
----
/gskd-display lite
/gskd-display normal
/gskd-display status
----

* `lite` 关闭终端图片、工作文字 shimmer 和子代理实时工具预览，收起代理列表，并以 `preserve` resize 策略保留历史换行、不回放整段历史。原本关闭的代理列表保持关闭；正文和工具输出仍流式显示，不改状态栏布局。
* `normal` 释放预设覆盖，恢复启用前的运行时覆盖状态，不重置为默认值；期间手动改为其它值的设置保留。重复 `lite` 不重拍快照。
* 默认命令与 `status` 查看状态。设置不落盘，新进程默认不启用。

这不是静态执行模式：工具旋转图标、计时和终端标题动画仍可能刷新。预设不调用宿主私有组件接口、不新增轮询，也不切换影响模型提示的图表设置；未测量手机网络流量或资源收益。

上述扩展命令均不触发模型请求，也不向模型上下文添加消息。

=== Skill 使用洞察

`skill-insights` 为 skill 迭代积累本地读取事实、显式反馈与模型分析候选，不修改 skill、不自动执行建议，也不把结果注入主对话。

[source,text]
----
/gskd-insights
/gskd-insights --all
/gskd-insights gskd-orient --since 2026-10-01
/gskd-insights analysis status
/gskd-insights analysis off
/gskd-insights analysis on
/gskd-insights analysis run
/gskd-insights advice
/gskd-insights advice gskd-orient --since 2026-10-01
/gskd-insights feedback 这里应该先讨论方案
/gskd-insights feedback --skill gskd-orient 这里应该先讨论方案
/gskd-insights feedback positive --skill gskd-orient 本次明确区分了调查与实施授权
/gskd-insights feedback list
/gskd-insights feedback confirm <analysis-id>:<index>
/gskd-insights feedback reject <analysis-id>:<index>
----

* 默认查询当前项目；`--all` 查询当前 profile 全部项目，可按 skill 名称和 `--since` 起始日期筛选。显示入口／参考资料读取次数、会话数、重复读取、最近读取、返回文本版本与字节量，以及显式反馈、模型候选及确认状态。返回文本哈希不是完整 skill 文件或整个资料目录的版本，也不等于计费 token。
* 只根据成功的 `read` 回执采集读取事实；同一调用去重，主动重复读取分别计数。通过注册的 skill 路径或宿主结构化来源回执识别，不信任普通文件正文中的伪造标记；入口和参考资料归到同一来源，兼容 raw 读取及禁用 skill 命令的配置。命令列表只证明命令已注册，不证明模型可见；无法确认的路径不猜测。bash／eval 内部读取、自动注入及未转发到扩展的子代理事件不保证覆盖，不回填安装前历史。
* 一句话反馈自动绑定项目、会话位置和当前分支附近的读取记录；只有一个 skill／来源组合时预填关联，否则记为 `unknown`。同名但不同来源不会自动合并；自动预填的关联不是用户确认的归因，`--skill` 可明确指定，包括尚未读取的 skill。反馈原文保留，默认分类为未确定；正面反馈使用 `feedback positive`。
* **空闲旁路分析默认开启**，当前 profile 持久保存开关。主会话空闲 240 秒且无编辑草稿、排队消息和运行任务时，用当前会话模型分析固定消息片段；长记录分批处理，并保留片段锚点与成功覆盖范围。辅助读取／注册证据只取当前分支及共享根位置，最多检查最近 100 条、发送 16,000 字节，并向模型报告省略数量。独立请求不携带工具，不向主上下文写入内容；未发现候选不等于执行成功。
* **旁路分析与 `advice` 可能向当前模型服务发送数据并产生费用**，首次加载会提示。`analysis off` 不停止事实采集或清除已有结果；取消等待任务并请求取消在途分析，迟到结果不入库，上游可能已计费。同 profile 其它实例的自动分析在运行期间每秒检查开关，提交时再次检查。新输入、终端活动、压缩、会话切换和退出也会取消旧请求。
* `analysis run` 为用户显式发起，关闭自动分析时仍可使用；每次处理一个有界批次，成功后自动模式可继续处理后续批次。失败／取消不推进覆盖，失败不会立即自动重试；新活动或手动命令可再次触发。`status` 查看待分析片段数、当前模型、最近状态与存储位置。
* 压缩开始后暂停旁路调度，收到压缩完成／自动压缩结束事件，或下一轮主任务开始后恢复。宿主手动压缩失败或被其它扩展取消时可能不发结束事件；此时保守保持暂停，下一轮主任务恢复，不把缺少通知当成已空闲。
* 模型提取的分类、章节归属和重复问题标签都是候选，保留证据锚点；`feedback list` 查看候选 ID，按需确认或拒绝。统计取同一候选的最新决定，重复确认不增加候选数。读取不证明遵守，普通无反馈样本不算成功，不生成综合质量分。
* `advice` **仅由用户显式触发，方向是系统向用户提供 skill 使用建议**。它只读取所选范围已有的统计与反馈，不额外加载会话正文，不隐式启动反馈分析，也不推进分析覆盖；使用当前模型，按输入上限选择近期完整记录并报告省略数量。建议注明观察／推断及记录 ID，不自动执行、不改 skill；自动空闲分析不会生成建议。

数据保存到当前 profile 的 agent 数据目录下 `gskd-skill-insights.sqlite`，SQLite 持久化并支持并发写入；事实、分析与人工决定分别保留。数据库及伴随文件使用私有权限，不改变已有 profile 目录权限。显式反馈和模型候选可能包含敏感内容；消息锚点所指的原会话删除后，不保证仍可回查。该扩展不另存完整会话副本；完整内容沿用下述会话导出。

=== 本地会话导出

需要系统 PATH 中有 `tar` 和 `zstd`。缺少依赖时命令会明确报错。

[source,text]
----
/gskd-export
/gskd-export --all
/gskd-export --source "/path/to/agent" --out "/path/to/exports"
/gskd-export --stats
/gskd-export --stats-only
----

默认完整导出当前项目；`--all` 选择当前 profile 的全部项目，并保留当前会话自定义的 session 目录，不因扩大范围丢失当前会话。`--source` 指定包含 `sessions/` 的 agent 数据根目录（显式指定时不额外采集当前会话目录），`--out` 覆盖本地输出目录。路径含空格时加引号。命令不调用模型，不后台采集。

`--stats` 在原有完整导出中附加 `statistics.json`，包含所选项目范围的洞察事件、原始反馈、候选、决定与分析覆盖，并参与哈希清单。`--stats-only` 仅导出统计快照和清单，不要求存在会话目录；`--all` 同样扩大统计范围。统计从所选 `--source` 根目录的 `gskd-skill-insights.sqlite` 读取一致的逻辑快照，不复制活动数据库／WAL 文件；缺少数据库时导出空统计。导出不启动或等待模型分析，因此未分析内容可能尚无候选。仅统计不等于脱敏：反馈与候选正文、路径仍原样保留，分享前须检查。

包格式为 `.tar.zst`，文件名为 `omp-sessions_<本地时间YYYYMMDD-HHmmss>_<8位随机十六进制ID>.tar.zst`，不带时区；清单中的 `createdAt` 保留同一时刻的 UTC 时间。保留原始会话、关联子会话和会话附件，附文件哈希清单；不脱敏正文，不打包整个配置目录或项目源码。工具输出中已有的代码、密钥等内容会原样保留。仅识别为会话日志的 JSONL 截取完整事件，未完成部分留到下次；普通附件（包括 `.jsonl` 文件）按原始字节保留。

关联采集按会话头中的 `parentSession` 与 `seanceSource` 持续展开，新纳入的来源会话也会继续关联其子会话；循环引用按文件路径去重。来源可位于已选存储根目录内的嵌套会话目录，但不跟随符号链接、不读取范围外来源，也不根据聊天正文中的路径采集文件。

可选配置放在当前 profile 的用户 `.env` 中，修改后重启 omp：

[source,dotenv]
----
GSKD_EXPORT_DIR=~/.omp/exports
----

未设置 `GSKD_EXPORT_DIR` 时，默认保存到当前 profile 的 agent 数据目录下的 `exports/`（普通默认 profile 通常为 `~/.omp/agent/exports/`）；`--out` 优先于环境变量。

每次生成独立的完整本地快照，不发送网络请求，不维护增量进度。命令完成后显示保存位置。它仅导出磁盘上已保存的内容，不是源码备份或可直接恢复整个开发环境的迁移包；压缩包未加密，分享前应检查其中的敏感内容。
