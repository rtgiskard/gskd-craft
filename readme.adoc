= gskd craft

工程协作 skills 与 omp 配套扩展，覆盖任务续接、设计取舍、界面验证、交付复查和脉络回顾。
Skills 可按目标宿主的约定接入；扩展仅用于 omp。

== 接入与更新

=== omp

将仓库克隆到独立源码目录，在仓库根执行：

[source,shell]
----
omp plugin link .
----

启动新会话后，omp 会自动发现 skills 并加载扩展。链接直接指向源码，无需复制文件或安装额外依赖，也不搬迁现有配置、凭证和会话数据。
使用命名 profile 时，改用 `omp --profile work plugin link .`。
更新仓库后，启动新会话即可加载更新。

=== 其它宿主

按宿主的安装或发现约定接入 `skills/` 下的 skill 目录。每个 skill 以 `SKILL.md` 为入口，补充资料位于其 `references/`；迁移时保留完整目录和相对引用。
`extensions/` 下的 omp 扩展不适用于其它宿主。

== Skills

* `gskd-orient`：处理补充、纠正、工作项插入、并行安排与暂停续接
* `gskd-design-review`：检查设计取舍、责任边界、生命周期与实际接入
* `gskd-gui-verification`：验证真实界面、输入交互及平台行为
* `gskd-delivery-review`：对照已接受要求，核对实现、证据和交付边界
* `gskd-recap`：梳理分析、决定、进展和续接位置，不自动执行历史任务；默认简明表格，事项名称前配状态图标，按需分表并共用图例，也可用自然语言选择状态分组、主题分组或时间线；详略与形式独立

各 skill 按需使用，不组成固定流水线；实际能力由宿主工具、权限和环境决定。已读内容仍适用时可复用，新证据引出疑点时只检查受影响边界。发现、读取或注入 skill 不等于落实其要求，应以实际行动和证据判断。

== omp 扩展

=== 故障自动续接

`task-recovery` 默认开启，为仍在运行的主会话续接暂时性上游通信故障，包括连接失败、超时、流异常结束、临时服务错误和限流。

[source,text]
----
/gskd-recovery status
/gskd-recovery off
/gskd-recovery on
----

* 优先让宿主内置恢复接管；仍未恢复时，按 30、60、120、300 秒逐步等待，附加少量抖动，并遵守可获得的服务端等待提示。明确的临时故障不设累计次数上限；未确认的通信故障最多试探两次。
* 账户额度耗尽、认证与配置错误、正常完成或主动取消不会反复续接；临时限流沿用宿主分类，不仅凭 quota／billing 等关键词判断。
* 沿用原会话和工具结果，不重放整个任务。缺少工具回执、无法确认是否执行时暂停并提示核实。
* 仅在冷却等待时于输入框上方显示提示，不占底部状态栏。`off` 取消待恢复任务；`on` 仅对后续故障生效。
* 续接回合正常结束且回执齐全才记为成功，统计含冷却等待的累计耗时及最近完成时间；同一恢复过程只计一次。`status` 查看统计，下一次输入或 recovery 命令会一次性提醒未读成功记录。统计仅存于当前会话内存，不代表业务任务完成。

支持存活的 TUI、长驻 RPC 和 SDK 主会话，不用于同进程子代理或已退出的一次性 print/json 进程。不重启 omp、不切换模型、不修改全局配置，也不要求额外 checkpoint。
TUI 的 Esc/Ctrl-C、停止、新输入和会话切换会撤销旧恢复；已提交的续接无法撤回。非 TUI 若缺少停止信号，可用 `off` 显式取消。

=== 工作树执行位置

`worktree-location` 观察主会话最近一次 bash 执行声明的目录，也支持通过 `write xd://bash` 发起的执行。在其它工作树执行时，于输入区下方靠右显示单行 `wt: 工作树 · 分支`，不附加前导空行，不改底部状态栏；回到会话工作树后隐藏。若显式约定与实际位置不一致，仍保留偏离提示。

[source,text]
----
/gskd-worktree status
/gskd-worktree set <path>
/gskd-worktree clear
----

* 默认命令与 `status` 查看完整路径、分支、HEAD、观测来源和显式约定。
* `set` 仅绑定任务工作树，不切目录；尚未观测执行时不显示常驻行。`clear` 清除约定，保留最近执行记录。
* 只依据结构化 `bash.cwd`，缺省采用会话目录；不追踪 shell 内部 `cd`、`git -C`、远端目录或产物来源。沿用宿主路径规则，包括 `/` 的工作区别名、`@` 前缀和 `file://`；显式 `set /` 仍指文件系统根目录。
* 最终位置以规范执行回执为准；等待回执时标为待确认。审批拒绝或未执行不算观测，已执行的非零退出和超时仍可记录。目录或 Git 信息不可用时不猜测分支。
* 已确认状态随成功的会话／分支切换恢复；旧回执或查询不能覆盖更新状态，也不能跨入新会话。取消会话切换不丢弃仍有效的在途观测。

执行 `/move` 或迁移工作区后，用 `status` 或下一次 bash 执行刷新基准与显示；宿主清除提示后也可这样恢复。扩展不轮询目录、不修改宿主、不拦截执行或注入模型上下文；非 TUI 仅通过命令查看。

=== 轻量显示预设

`display-preset` 仅用于主 TUI 会话，按需启用：

[source,text]
----
/gskd-display lite
/gskd-display normal
/gskd-display status
----

* `lite` 关闭终端图片、工作文字 shimmer 和子代理实时工具预览，收起代理列表，并以 `preserve` resize 策略保留历史换行、不回放整段历史。原本关闭的代理列表保持关闭；正文和工具输出仍流式显示，不改状态栏布局。
* `normal` 释放预设覆盖，恢复启用前的运行时覆盖状态，不重置为默认值；期间手动改为其它值的设置保留。重复 `lite` 不重拍快照。
* 默认命令与 `status` 查看状态。设置不落盘，新进程默认不启用。

这不是静态执行模式：工具旋转图标、计时和终端标题动画仍可能刷新。预设不调用宿主私有组件接口、不新增轮询，也不切换影响模型提示的图表设置；未测量手机网络流量或资源收益。

上述扩展命令均不触发模型请求，也不向模型上下文添加消息。
