# GUI 行为与视觉验证

## 何时使用

先确定本次需要回答的是改造是否正确、故障原因，还是某个实际状态的效果。准备深度由目标决定，代码检查不是所有实际界面取证的统一前置。

- **改造或故障验证**：先检查与当前问题相关的实现、调用链、状态与生命周期边界及现有测试，确定待验证行为和证据缺口。涉及 UI 代码本身不自动要求启动界面；可由代码与针对性检查充分验证的逻辑改动，不因所属模块是 GUI 就启动界面。
- **查看指定实际状态**：用户仅要求查看现有页面或状态时，确认目标实例、访问权限和当前状态后直接取证；不要求先审查无关实现、测试和生命周期。若状态无法进入、取证需要改变实现，或出现具体异常，再做必要调查，并核对相应操作是否在授权内。

以下任一条件成立时，进入目标明确的实际界面取证：

- 用户明确要求实际界面、交互或视觉验证。
- 本次验收依赖代码层无法证明的实际表面、输入交付或平台集成，例如布局／视觉效果、焦点、拖放、IME、窗口与桌面行为。
- 代码与现有测试仍留下具体 GUI 疑点，需要实际运行区分原因或确认结果；先写明疑点和待观察结果，不以泛泛的“证据不足”展开 GUI 全面审查。

只验证上述目标及受影响的邻接边界，不扩成全界面巡检。代码层证据不能替代已明确要求的 GUI 验收；无需 GUI 时也不将未执行的交互或视觉效果写成通过。本 Skill 是工作方法，不提供现成工具或新增实施授权。

## 判断与执行

1. **确定目标。** 写明初始状态、操作、期望变化和不能发生的副作用。用户认可的目标效果与修改前实现不是同一基准。接受用户报告；复现用于定位或建立对照，不用于反复确认用户是否说对。无法运行旧版本就标明缺少前对照。
2. **选择输入层。** 按待证明的事实选择路径：查看页面效果，取得目标状态的真实渲染；验证交互，让输入经过待验路径；验证平台输入交付，使用相应真实环境。结合可用工具选择路线，仅在选择路径或解释结果需要时检查相关实现与测试。控件事件注入适合精确定位，但不证明平台输入交付；直接调用业务函数不能证明按钮可操作。无需在无关层重复场景。
3. **准备隔离。** 遵守本地存储和资源约束，使用任务独立的数据、配置、用户会话或浏览器上下文；确认应用、输入控制和截图指向同一实例。不要操作用户现用实例，不假定历史工具、端口或路径仍存在。固定构建、输入数据、窗口、字体及缩放；有界等待实际就绪，不以固定 sleep 代替成功条件。
4. **执行与观察。** 让输入经过待验路径，观察操作前、过程中与操作后的实际表面。拖动覆盖按下、移动、释放及相关取消路径。截图必须查看；后台状态与持久化结果只查询同一任务实例。动态显示检查时间过程，不只看一张静态图。用户要求查看特定状态的实际效果时，应取得该状态的真实渲染结果；注明示意或近似来源不等于满足原验收，不能默认用其替代。
5. **检查正反结果。** 不只判断未崩溃、弹窗消失或图片产生。例如外部点击应关闭菜单但不误触底层控件，随后正常点击仍有效；取消拖放不改变布局；保存与放弃分别兑现草稿契约。具体预期从当前项目要求取得，不硬套其他项目。
   涉及视觉或动态取舍时，依照设计评审的美学品味尺度，在实际页面、相邻组件及必要的时间过程中观察层次、比例与节奏是否符合目标；不只看孤立组件或尺寸值是否统一。将实际观察与审美判断分开说明，功能验收通过不自动证明美学目标满足；只补本次目标所需证据，不扩成全界面巡检。
   品味尺度见 [gskd-design-review 的“表达与美学品味”](../gskd-design-review/SKILL.md#表达与美学品味)；需要且当前上下文尚未包含时补读该部分，不因此重新比较或改换已接受方案。
6. **验证最终版本并清理。** 临时 hook 只用于诊断；移除后重新构建并补验关键实际路径。永久测试只保留真实行为回归价值。按目标应用的生命周期停止任务实例及辅助进程，不假定关窗口等于服务退出；只清理确认归属且不再使用的产物。

## 按需参考

- 外观回归、渲染优化或资源比较：按 [视觉与资源对照](references/visual-comparison.md) 的对应小节补读；基准疑问看“先确定比较对象”，等价性看“把语义与实现拆开验证”，画面对照看“获得可比较的画面”，测量看“资源测量”，释放看“生命周期”，示意与实拍看“实际状态与概念示意不能互换”。不必通读无关小节；普通控件不增加性能矩阵，音频可视化例子不构成通用需求。
- 平台与项目操作按目标仓库提供的验证 skill 或文档执行；先发现可用工具，不预设 compositor、命令或缓存路径。项目约束优先于本通用方法。

## 产出与停止

简述构建及环境、实际输入层、表面观察、状态变化与不变、未覆盖项，给出证据位置。视觉、行为与资源收益分别下结论；未执行的操作不能写成通过。没有可用真实表面时，报告已经覆盖的层和具体缺口，不拿示意图、离屏图或测试日志替代。

本轮验收满足且没有新的实质失败证据就停止，不机械展开全部参考。平台验证受阻时完成可达部分；若该平台行为正是验收目标，明确阻塞而非宣布交付。Skill 的使用本身不证明验收成功。
